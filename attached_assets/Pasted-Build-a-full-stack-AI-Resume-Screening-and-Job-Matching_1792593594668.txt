Build a full-stack AI Resume Screening and Job Matching Platform using the Kaggle dataset "AI Resume Screening and Hiring Analytics Dataset".

Project Goal:
Create an AI-powered recruitment platform that analyzes resumes, predicts candidate suitability, ranks applicants, and provides hiring recommendations.

Core Features:

1. Resume Upload
- Upload PDF or DOCX resumes.
- Extract text automatically.
- Store parsed resume data in a database.

2. Candidate Analysis
- Extract:
  - Skills
  - Education
  - Experience
  - Certifications
  - Projects
- Generate a candidate profile summary.

3. Resume Screening
- Train a machine learning model using the Kaggle dataset.
- Predict:
  - Candidate suitability score
  - Shortlist recommendation
  - Hiring recommendation
- Display confidence scores.

4. Candidate Ranking
- Rank all uploaded resumes.
- Sort by:
  - Match score
  - Experience
  - Skills relevance
  - Education score

5. AI Career Assistant
- Integrate OpenRouter API.
- Use a free model such as Qwen 2.5 or Llama 3.
- Explain:
  - Why candidate received a score.
  - Missing skills.
  - Resume improvements.
  - Recommended career paths.

6. Job Matching
- User enters a job description.
- Compare resumes against the job.
- Calculate:
  - Skill match percentage
  - Experience match percentage
  - Overall compatibility score
- Show matched and missing skills.

7. Analytics Dashboard
- Visualize:
  - Candidate distribution
  - Top skills
  - Hiring recommendations
  - Resume scores
  - Screening statistics

8. Search and Filters
- Search candidates by:
  - Skill
  - Education
  - Experience
- Filter shortlisted candidates.

9. Export Features
- Export candidate reports as PDF.
- Download ranking results as CSV.
