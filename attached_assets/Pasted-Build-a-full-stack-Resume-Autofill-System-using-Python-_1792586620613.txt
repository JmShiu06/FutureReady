Build a full-stack Resume Autofill System using Python, Flask, Regex, spaCy, and a Skills Dictionary. Do NOT use any LLM, OpenAI API, Gemini, Claude, or generative AI.

Objective:
Users upload a CV (PDF or image). OCR text will already be provided as plain text. The system should extract structured information and automatically fill a form.

Tech Stack:
- Python
- Flask
- spaCy (en_core_web_sm)
- Regex
- HTML/CSS/JavaScript
- Bootstrap
- JSON

- Display extracted text.
