Build a backend service called Skill Learning Recommendation Engine.

Objective:
Use the existing AI Skill Analysis Engine to analyze a user's CV and automatically recommend courses that help improve missing or weak skills.

The skill analysis engine already provides:

{
  "technical_skills": [],
  "soft_skills": [],
  "skill_scores": {},
  "missing_skills": [],
  "candidate_level": "",
  "career_path": ""
}

DO NOT rebuild the skill analysis engine.

Instead, consume its output and generate personalized course recommendations.

Datasets:

1. Resume Analysis Dataset
- AI Resume Screening and Hiring Analytics Dataset

2. Course Dataset
- Coursera Courses Dataset
- EdX/Coursera/Udemy Course Dataset
- Online Courses Dataset

System Workflow:

Step 1:
Receive analysis results from the existing AI engine.

Step 2:
Extract:
- Missing skills
- Weak skills
- Career interests
- Skill maturity scores

Step 3:
Search course dataset.

Step 4:
Match courses to:
- Missing skills
- Weak skills
- Career goals

Step 5:
Rank courses based on:
- Skill relevance
- Difficulty level
- Course rating
- Learning sequence

Step 6:
Generate a personalized learning roadmap.

Recommendation Logic:

IF skill score < 60:
    Recommend Beginner courses.

IF skill score 60-80:
    Recommend Intermediate courses.

IF skill score > 80:
    Recommend Advanced courses.

Generate recommendations for:

- Technical Skills
- Soft Skills
- Certifications
- Career Development

Use semantic matching with sentence-transformers.

Use embeddings to compare:
- Missing skill
- Course description
- Course learning outcomes

Backend Stack:

- Python
- FastAPI
- Pandas
- PostgreSQL
- ChromaDB
- Sentence Transformers

API Endpoints:

POST /recommend-courses

Input:

{
  "user_id": "123",
  "analysis": {
    "technical_skills": [
      "Python",
      "SQL"
    ],
    "missing_skills": [
      "Docker",
      "AWS"
    ],
    "skill_scores": {
      "Python": 85,
      "SQL": 65,
      "Docker": 20,
      "AWS": 10
    }
  }
}

Output:

{
  "recommended_courses": [
    {
      "course_name": "",
      "platform": "",
      "difficulty": "",
      "skills_covered": [],
      "match_score": 0,
      "course_url": ""
    }
  ]
}

Learning Roadmap Requirements:

- Prioritize foundational skills first.
- Build prerequisite chains.
- Avoid recommending advanced courses before beginner courses.
- Group recommendations by month.
- Estimate learning duration.
