Build a backend AI Skill Analysis Engine using the Kaggle "AI Resume Screening and Hiring Analytics Dataset".

Objective:
Create a machine learning and LLM-powered backend service that analyzes resumes and generates skill intelligence reports.

This is NOT a recruitment or applicant tracking system.

The system focuses on:

1. Skill Extraction
2. Skill Gap Analysis
3. Career Path Prediction
4. Learning Recommendations
5. Resume Intelligence
6. Labor Market Readiness Assessment

Backend Only Architecture

Tech Stack:
- Python
- FastAPI
- Scikit-learn
- Pandas
- NumPy
- Sentence Transformers
- ChromaDB
- OpenRouter API
- PostgreSQL

Machine Learning Pipeline:

Step 1:
Load and preprocess the Kaggle dataset.

Step 2:
Extract features:
- Technical Skills
- Soft Skills
- Education
- Certifications
- Experience Level
- Industry Domain

Step 3:
Create skill embeddings using sentence-transformers.

Step 4:
Build a similarity engine that identifies similar candidate profiles.

Step 5:
Train models to predict:
- Candidate skill category
- Career level
- Domain specialization
- Employability readiness score

Generate the following outputs:

Skill Analysis Report:

{
  "skill_score": 87,
  "technical_skills": [],
  "soft_skills": [],
  "missing_skills": [],
  "emerging_skills": [],
  "recommended_learning_path": [],
  "career_readiness": "",
  "candidate_level": "",
  "similar_profiles": []
}

Core API Endpoints:

POST /analyze-resume

Input:
{
  "resume_text": ""
}

Output:
{
  "technical_skills": [],
  "soft_skills": [],
  "education_level": "",
  "experience_level": "",
  "skill_score": 0
}

POST /skill-gap-analysis

Input:
{
  "resume_text": "",
  "target_role": "Backend Developer"
}

Output:
{
  "current_skills": [],
  "missing_skills": [],
  "recommended_courses": [],
  "estimated_learning_time": ""
}

POST /career-path

Input:
{
  "resume_text": ""
}

Output:
{
  "suitable_roles": [],
  "confidence_scores": [],
  "growth_path": []
}

POST /profile-similarity

Input:
{
  "resume_text": ""
}

Output:
{
  "similar_profiles": [],
  "common_skills": [],
  "recommended_next_skills": []
}
